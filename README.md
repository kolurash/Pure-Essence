# 🌿 Pure Essence – Home Remedies & Wellness Website

Pure Essence is a responsive wellness website that provides users with natural home remedies, healthy lifestyle tips, and wellness information through a clean and user-friendly interface.

🔗 **Live Demo:** https://kolurash.github.io/Pure-Essence/

---

## 📖 About the Project

Pure Essence is designed to promote natural healthcare by offering information about home remedies for common health issues. The website features an attractive UI, responsive design, and easy navigation, making wellness information accessible on both desktop and mobile devices.

---

## ✨ Features

- 🌱 Clean and modern user interface
- 📱 Fully responsive design
- 🏠 Home remedies for common health problems
- 🔍 Easy navigation
- 💻 Cross-browser compatibility
- ⚡ Fast loading static website

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kolurash/Pure-Essence.git
```

### Open the Project

Simply open `index.html` in your browser.

Or use VS Code Live Server:

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.
